# 05: 制作人档案

**What to build:** 用户在设置页编辑自己的制作人档案，包括称呼、性别和时区。没有设置的项沿用默认值：称呼按角色的人设，性别沿用原作中男性制作人的设定，时区取浏览器检测到的值，检测不到时用 Asia/Shanghai。档案会进入提示词，角色能知道按用户时区计算的现实当前日期和时间。档案只影响角色当下怎么对待用户，不改写剧情。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 提供读取和更新制作人档案的接口，档案属于用户而不属于某一把访问密钥
- [ ] 设置了称呼后，提示词中包含该称呼，并说明它只是叫法、用户仍然是制作人
- [ ] 没有设置称呼时，提示词不覆盖人设中的默认称呼
- [ ] 设置的性别会进入提示词；没有设置时沿用原作设定
- [ ] 提示词中的当前日期和时间按用户的时区计算（测试中固定当前时间）
- [ ] 用户没有手动设置时区时，前端使用浏览器检测到的时区，检测不到时回退到 Asia/Shanghai
- [ ] 设置页可以编辑并保存称呼、性别、时区

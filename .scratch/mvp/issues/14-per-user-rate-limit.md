# 14: 按用户限流

**What to build:** 按用户统计用量并限流，避免某位用户用得太多，把大家共用的 API 额度耗光。超过限额时，前端显示友好的提示，并告诉用户什么时候可以再用。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 文字对话回合和语音连接都按用户计入用量（同一位用户的多把访问密钥合并计算）
- [ ] 限额可以配置（参考项目的默认值是每小时 5 次连接）
- [ ] 超过限额时拒绝请求，并返回可以恢复使用的时间
- [ ] 前端对超额情况显示友好的提示
- [ ] 以上行为都有通过后端对外接口驱动的测试（使用可控的时钟）

# 15: VPS 部署

**What to build:** 管理员用一条命令把整套服务部署到 VPS 上，包括生产环境的 Docker Compose 配置、HTTPS，以及 WebRTC 中继所需的 TURN/ICE 配置。部署完成后，小圈子里的朋友用手机或电脑访问公网地址，填入访问密钥，就能和角色通话。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 生产环境的 Docker Compose 配置与开发环境分开，所有密钥都通过环境变量注入，不进仓库
- [ ] 全站通过 HTTPS 访问（浏览器只有在 HTTPS 下才允许使用麦克风）
- [ ] 配置 TURN 服务，在常见的 NAT 和移动网络环境下也能建立语音连接
- [ ] 剧情库数据、人设文件和数据库都放在持久化卷中，升级服务时不会丢失
- [ ] 有一份部署说明：需要准备哪些环境变量、如何导入剧情库、如何签发访问密钥
- [ ] 手动验收：用手机通过公网完成一次真实通话

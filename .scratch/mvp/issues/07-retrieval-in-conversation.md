# 07: 对话中检索剧情与角色资料

**What to build:** 每一句话，对话引擎先让 Jev（通过 Vercel AI Gateway 调用）判断是否需要检索。需要时，从剧情库中检索当前角色出场过的剧情，同时检索角色资料，用硅基流动的 Qwen3-Reranker 重排后放进提示词。这样角色聊天时能自然地提起自己真正经历过的剧情，而不会把别的偶像的剧情说成自己的。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] Jev 判断不需要检索时，本回合不做检索（测试中用假判断器验证）
- [ ] 剧情检索按出场角色过滤：真乃的对话检索不到她没有出场的剧情
- [ ] 支持角色资料（档案与人物关系）的配置和检索，检索结果会进入提示词
- [ ] 检索结果先重排再进入提示词，数量有上限
- [ ] Jev、向量化、重排服务都通过接口注入，测试中使用假实现
- [ ] 以上行为都有通过后端对外接口驱动的测试

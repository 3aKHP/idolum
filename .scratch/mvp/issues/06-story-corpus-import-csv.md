# 06: 剧情库导入（CSV）

**What to build:** 管理员用一条导入命令，把 SCTranslationData 格式的剧情 CSV（`id,name,text,trans`，末尾有一行 `info` 指向原始剧本）导入剧情库。每段剧情带有分类、出处（卡或活动）、标题、出场角色，以及按说话人分好的台词，并通过硅基流动的 Qwen3-Embedding 写入向量索引。只收录正式经历，排除失败结局；重复导入是幂等的。这一步同时建立切入点 B 的测试。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 导入命令接收一个 CSV 目录，把每个文件导入为一段剧情
- [ ] 根据说话人识别出场角色，并映射到 03 中配置的角色规范标识；制作人（台词 id 为全零）和非角色人物不算出场角色
- [ ] 失败结局（例如 W.I.N.G. 敗退）不会被导入
- [ ] 以剧情的来源标识为主键，重复导入同一个文件时覆盖更新，不产生重复
- [ ] 剧情写入向量索引，支持按出场角色过滤检索
- [ ] 整理后的剧情库数据被 git 忽略（ADR-0003）
- [ ] 切入点 B 的测试：导入一小组样例 CSV（包含成功与失败结局、多个出场角色、非角色说话人）后，通过查询验证以上规则；向量化使用假实现

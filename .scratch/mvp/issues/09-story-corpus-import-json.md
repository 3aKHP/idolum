# 09: 原始剧本 JSON 导入补全

**What to build:** SCTranslationData 里缺少的剧情，由管理员用插件导出游戏原始剧本 JSON（字段包括 speaker、text、select、voice 等），再导入剧情库补全。JSON 导入和 CSV 导入遵循同样的正式经历规则：选项分支只保留角色的反应，不认定制作人当时选了哪一项。同一段剧情如果已经通过 CSV 导入过，不会重复入库。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 导入命令支持游戏原始剧本 JSON
- [ ] 选项分支：保留角色对每个选项的反应，但剧情内容不认定制作人选了哪一项
- [ ] 同样排除失败结局
- [ ] 同一段剧情分别通过 CSV 和 JSON 导入时，只保留一份（按来源标识去重）
- [ ] 只通过 JSON 导入的剧情没有中文翻译，但检索和剧情目录都能正常使用
- [ ] 切入点 B 的测试：包含选项分支的样例 JSON，以及 CSV 和 JSON 重叠的情况

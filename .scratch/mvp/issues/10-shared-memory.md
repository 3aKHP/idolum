# 10: 记忆的抽取与共享检索

**What to build:** 新增「后台模型」配置。后台模型在对话中抽取关于用户的中文记忆，每条记忆都带上所属用户和来源角色。之后的对话中，对话引擎会检索当前用户的记忆放进提示词；如果一条记忆的来源不是当前角色，就要求角色用转述的口吻提起（ADR-0002）。这样用户对真乃说过的事，恋鐘也会以「听真乃说……」的口吻知道；不同用户之间的记忆则完全隔离。新对话只靠检索到的记忆接上以前聊过的事，不另外带上次对话的摘要。

**Blocked by:** 02, 03, 07

**Status:** ready-for-agent

- [ ] 支持单独配置「后台模型」，与对话模型分开
- [ ] 对话中透露的信息会被抽取成中文记忆，并记录所属用户和来源角色
- [ ] 新对话中，与当前话题相关的记忆会进入提示词
- [ ] 提示词中标注每条记忆的来源角色；来源不是当前角色时，附带「用转述的口吻提起」的要求
- [ ] 用户 A 的记忆永远不会出现在用户 B 的对话中
- [ ] 测试：用户对真乃说了一件事之后，在和恋鐘的对话中，假 LLM 收到的提示词包含这条记忆，且来源角色为真乃

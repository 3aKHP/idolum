# 12: 人设初稿生成命令

**What to build:** 管理员用一条命令，让后台模型根据某位角色出场过的剧情，生成这位角色的人设草稿（身份、自称、对他人的称呼、口癖、组合成员、硬性规则），写入人设文件，供人工校对后使用。

**Blocked by:** 06, 10

**Status:** ready-for-agent

- [ ] 命令接收一个角色标识，只用该角色出场过的剧情作为素材
- [ ] 生成的草稿包含人设要求的各个部分，并明确标记为草稿
- [ ] 默认不覆盖已存在且经过人工校对的人设文件，只有显式指定时才覆盖
- [ ] 剧情素材超出模型的上下文长度时，先采样或分批总结，而不是直接失败
- [ ] 测试：使用假的后台模型，验证素材只来自该角色出场过的剧情，以及已有文件不会被覆盖

# 04: 语音通话

**What to build:** 用户在对话页和角色进行实时语音通话。Pipecat 管线只是对话引擎外面的一层：Soniox 语音识别 → 对话引擎 → Fish Audio 只合成日语部分，中文字幕通过数据通道推送到前端。通话中打字输入的内容进入同一条对话；静音开关打开时只显示文字、不播放语音。建立连接时要校验访问密钥。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 后端提供 WebRTC 信令接口和 ICE 服务器配置接口，建立连接时校验访问密钥和角色标识
- [ ] 中文、日文说话都能被正确识别（Soniox 中日文混合识别）
- [ ] 角色语音使用该角色配置的 Fish Audio 音色，只读日语原文
- [ ] 每句回复的日语原文和中文字幕实时显示在对话页上，和语音对得上
- [ ] 通话中打字输入的内容和语音输入记录在同一条对话里，角色同样以语音加文字回复
- [ ] 打开静音开关后只显示文字，不播放语音
- [ ] 设置页可以选择麦克风和通话音质
- [ ] 不使用 Pipecat 自带的 LLM 服务和上下文聚合器，对话逻辑全部由对话引擎处理
- [ ] 手动验收：和真乃、恋鐘各通一次电话，延迟可以接受，字幕和语音对得上

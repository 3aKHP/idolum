# Idolum：一个词的两千五百年

> 本文档是 Idolum 品牌故事的正本。README 的词源段从这里节选；引用时保持事实完整。

## 一个看见一切的词根

原始印欧词根 ***weid-**，「看见」。它的一支走进希腊语，变成 idein（看见）→ **eidos**（被看见的东西，即「形相」）→ **eidōlon**（εἴδωλον，被看见之物：影像、幻象）；另一支在拉丁语变成 **videre**（vision、video）；在梵语变成 **ved-**，即《吠陀》（Veda）；在日耳曼语变成 **wit / wise / wisdom**。

idol、Veda、video、wise 是同一个词根的堂兄弟。而柏拉图的 **idea**（真实之形）与 **eidōlon**（徒有其表之像）是同根的亲兄弟——整个柏拉图形而上学，就是这对兄弟争遗产：谁是真的？

## 第一站：希腊——中性的，甚至是科学的

荷马史诗里，冥府的亡者是 eidola：奥德修斯下冥界时，赫拉克勒斯本人已位列神班，他见到的只是那个 eidōlon——影像从不说自己是本人。德谟克利特和伊壁鸠鲁的视觉理论里，eidōlon 是物体表面剥落、飞入眼睛的薄膜——一个正经的物理学名词。色诺芬尼批评「人按自己的样子造神」，那是哲学内部的辩论，不是罪名。此时 eidōlon 无罪。

## 第二站：亚历山大港——一次翻译挖出的座位

公元前二世纪，七十士译本的犹太译者在亚历山大把希伯来经文译成希腊语。经文骂异教神像用的全是蔑称——gillulim（「粪土之神」或「木疙瘩」，以西结书用了四十多次）、elilim（「无价值之物」）。译者给这些骂人词找了希腊语的座位，选中了 eidōlon。

一个「影像」的中性词，从此坐进了「假神」的语义座位。与之对照：人按神的「形象」造，译作 eikōn（真像）——**eikōn 与 eidōlon 的对立，是翻译 politics 造出来的**。

## 第三站：罗马——住在哲学区的归化移民

idolum 进入拉丁语是希腊借词，古典时期用得不多、不带火药：西塞罗用它说幽灵、梦象与心象。罗马人自己更爱母语词——simulacrum、imago。idolum 住在哲学区，没参加过后来的神学战争；它的古典义「影像、心象」，正是我们取用的那一站。

## 第四站：教会的武器坊

德尔图良写下《论偶像崇拜》（De Idololatria），「偶像崇拜」这个合成武器出厂；哲罗姆的武加大译本把 eidōlon 固定为 idolum，钉进拉丁正典。神学上完成了漂亮的双重定罪：偶像**什么都不是**（以赛亚书的讽刺：一棵树，一半烤饼取暖，一半雕成神像下拜），**同时是恶魔**（「万国的神都是鬼魔」）。既空洞又危险——一个词背上两重罪。

## 第五站：暴力的年代

宗教改革用这套武器清算天主教圣像（1566 年尼德兰的圣像破坏风暴）；殖民时代，「idols / idolatry」进一步变成砸毁他者神像、焚烧经卷的法律-神学类目。这个词在近代史上沾过真实的血。这一站属于历史的垃圾堆——我们不背它，也不假装它不存在。

## 第六站：世俗赎回

1620 年，培根把 idola 变成认知谬误的学名：种族假相、市场假相、洞穴假相、剧场假相——偶像从「假神」变成「思维的系统性错误」。此后这个词一路漂白：十九世纪的剧场偶像、二十世纪的 teen idol、1970 年代初的アイドル歌手热潮，直到 IDOLM@STER 把它铸成整个行业的名字。**アイドル 是这个词漂白完成态的名字。**

顺带一提，宗教论战征用中性词铸武器，idolum 不是孤案：hairesis（「选择；思想流派」）成了 heresy，superstitio（罗马人眼中「过度的、外来的宗教狂热」）成了 superstition。同一种手法，同一个下场。认得出来，就不会再上当。

## 为什么是 Idolum

**idolum 是 eidōlon 进入拉丁语后的形态**——上游的名字是这个词的希腊语原形，我们的名字是它的拉丁语形态：同一个词，换了一种语言。这和项目本身互为镜像：她用日语原声回答、附中文字幕；我们的后端将在稳定后从 Python 走向 Go——这条线上的每一层，都是「同一个灵魂、下一种语言」。

它也是 **idol 的直系词源**（idol ← 古法语 idole ← idolum ← eidōlon）：アイドル、IDOLM@STER、整个偶像工业的名字都站在这条链的末端。这个词从希腊的「幻象」出发，途经荷马的冥府、德谟克利特的光学、亚历山大的译经室、哲罗姆的书房、培根的四假相，最后落在アイドル——**一个词花两千五百年学会扮演一个人**，恰好就是本项目讲的故事。

最后一个小彩蛋：-um 是中性名词主格，**复数是 idola**——一位角色是一位 idolum，283 事务所的全部偶像，是 idola。
